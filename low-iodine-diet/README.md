# 甲状腺放射性碘治疗前低碘饮食手机指南

这是一个面向手机竖屏阅读的低碘饮食静态页面。

## 发布地址

- 详细版：https://sailor-cmd.github.io/html-effectiveness-zh/low-iodine-diet/
- 简版打印页：https://sailor-cmd.github.io/html-effectiveness-zh/low-iodine-diet/simple-print.html
- 发布仓库：`sailor-cmd/html-effectiveness-zh`
- 发布提交：`0f660b7 Add concise printable low iodine guide`

## 内容目标

- 手机竖屏优先：首屏先给关键数字和行动入口，正文拆成短卡片。
- 日常可执行：包含每日预算、食物速查、标签关键词、14 天流程、样板菜单、购物清单。
- 数据量化：使用 `<50 mcg/日`、`14 天`、`0 次外食/海产品/加碘盐`、`170g/日新鲜肉类` 等执行口径。
- 图文并茂：使用 SVG + HTML/CSS 原生图解展示治疗原理、餐盘搭配和执行清单，避免手机端图片文字模糊。
- 简版打印：独立 `simple-print.html`，只保留严格不吃、少量吃、通常可吃和每日自查，适合 A4 打印。
